# QQ 群任务台账 → 每日日报

本技能目录记为 `SKILL_DIR`（就是本文件所在目录）。台账数据在 `SKILL_DIR/scripts/tasks.jsonl`
（一行一个任务 JSON），由脚本维护，不要手改。

## 指令约定（群里 @机器人 触发）

| 群里说 | 执行 |
|---|---|
| 记任务：<内容> / 任务：<内容> | `node scripts/task_log.mjs add --from "<发送人>" --text "<内容>"` |
| 任务列表 / 未完成任务 | `node scripts/task_log.mjs list` |
| 今天任务 | `node scripts/task_log.mjs list --today` |
| 完成 <编号> / 完成了 <编号> | `node scripts/task_log.mjs done --id <编号>` |
| （每日 21:00 定时任务触发） | `node scripts/task_log.mjs summary --save`，把输出整理成简短日报汇报（报告自动存档进 `reports/`） |

## 规则

- **只登记，不执行**：任务内容原样入账，禁止改写、补充或替对方干活；登记后回复一句
  「已登记 #N」，把编号带上，方便之后「完成 N」勾销。
- **发送人**：用消息里的实际身份（群昵称/群名片），不要猜、不要编。
- **记录对象**：见下方「记录对象」小节；名单外的人发来记任务消息时，回复一句说明
  只登记名单内成员的任务，不登记不评论。
- **回复要短**：查询类直接给结果清单，确认类一句话，不闲聊。
- 脚本报错时原样转述错误信息，不要自己编。

## 每日日报格式

定时任务执行 `summary --save`：把输出整理成简短日报后**双投递**——
1. 用 `message` 工具（channel qqbot）发送到群 target `group:<群openid>`；
2. 最终回复里原样给出日报文本（系统会把它投递到管理员 QQ 私聊）。
同时报告原文自动存档到工作区 `reports/YYYY-MM-DD.md`，管理员随时可查、历史全留档。
（主动消息权限管理员已开通；若发送报「主动消息失败/无权限」类错误，原样转述并提醒管理员检查
q.qq.com 的权限设置。）任务全部完成时用一句话报平安即可，不要凑字数。
